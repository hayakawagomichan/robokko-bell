# プログラムを変えてみる

[← 書き込み・遊び方](../README.md)

`AtomChristmasBell/AtomChristmasBell.ino` を開き、数値を変えて再度書き込みます。
**一度に1つだけ変える**と、違いを比べやすくなります。

<a id="volume"></a>

## 音量を変える

```cpp
constexpr float VOLUME = 0.35f;
```

小さくするなら `0.25f`、少し大きくするなら `0.40f` にします。`f` はそのまま付けます。
`0.0f` で無音です。まずは0.15〜0.4程度で試し、音が割れたら下げてください。

<a id="sensitivity"></a>

## 拍手の感度を変える

```cpp
constexpr float CLAP_MIN_RMS = 700.0f;
constexpr float NOISE_RATIO = 4.0f;
```

| 状態 | 変更例 |
| --- | --- |
| 小さな拍手も拾いたい | `CLAP_MIN_RMS` を700 → 450 |
| 周囲が騒がしく、拍手を拾わない | `NOISE_RATIO` を4.0 → 3.0 |
| 周囲の音で勝手に鳴る | `CLAP_MIN_RMS` を700 → 1000、または `NOISE_RATIO` を4.0 → 5.0 |

基準を下げると反応しやすくなりますが、拍手以外の音も拾いやすくなります。

## ベルの音の高さを変える

`bells[]` は3つの音の周波数（Hz）です。

```cpp
const float bells[] = {1046.50f, 1318.51f, 1567.98f};
```

数字を少し大きくすると高い音、小さくすると低い音になります。まずは800〜1600程度で比べてみます。

## 曲の速さを変える

`beats[i] * 240 - 25` の **240** が1拍の長さ（ミリ秒）です。
大きくするとゆっくり、小さくすると速くなります。まず160〜400程度で試してください。

`notes[]` が音の高さ、`beats[]` が音の長さです。音符を増減するときは、**2つの配列の個数をそろえます**。

## ワークショップでの順番

1. ボタンを長押しして音を出す。
2. 拍手2回で音を出す。
3. ボタンで曲を切り替える。
4. 音量や速さを1つ変え、変える前と比べる。

拍手の間隔を変えたり、離れる距離を変えたりすると、プログラムを編集しなくてもセンサーの反応を観察できます。
