# うまくいかないとき

[← 書き込み・遊び方](../README.md)

## PCに本体のポートが出ない

1. USBケーブルが**データ通信対応**か確認します。充電専用では書き込めません。
2. 別のUSBポートで試します。
3. 必要に応じて、[M5Stack公式製品ページのUSB Driver](https://docs.m5stack.com/en/atom/Atom_Voice)を確認し、OSに合うFTDIドライバーを導入します。

## コンパイルや書き込みに失敗する

- ボードは **ESP32 PICO-D4**、パッケージは **esp32 by Espressif Systems 3.3.8** です。
- ライブラリは **Adafruit NeoPixel 1.15.4** を使います。
- `driver/i2s_std.h` や `driver/i2s_pdm.h` が見つからない場合は、ESP32 2.xや別のボードを選んでいないか確認します。
- 書き込み速度は **115200** にします。実機確認では、高速設定で通信が中断したことがありました。
- シリアルモニタなど、同じポートを使う別アプリを閉じます。
- 本体を接続し直し、ポートを選び直します。

## 拍手に反応しない

1. 起動後、黄色から緑になるまで約2秒待ちます。起動時に騒がしかった場合は、静かにしてリセットします。
2. 本体を机に置き、20〜40cmくらいから拍手します。
3. 2回の間隔は**0.18〜0.9秒**。まず約0.4秒で試します。
4. マイク穴が塞がっていないか確認します。
5. 反応しにくければ[感度を調整](customize.md#sensitivity)します。

1回目を検出すると青になります。青になるのに鳴らないときは、2回目までの間隔を変えてください。
再生中と再生直後の約0.7秒は、次の拍手を受け付けません。

## 勝手に音が鳴る

短い音の大きさと間隔で検出するため、机を叩く音や短い大声にも反応することがあります。
机への振動を減らし、静かにしてリセットするか、[検出基準を高く](customize.md#sensitivity)します。

## 音が小さい・音が出ない

- まず、ボタンを約1秒押して白になったら離し、試聴します。
- スピーカー穴が飾りやテープで塞がっていないか確認します。
- 音量を変える場合は、[音量の設定](customize.md#volume)を変更して書き込みます。
- 音が割れる場合は音量を下げます。メーカーは長時間の連続再生や大音量の矩形波などを避けるよう案内しています。[メーカーの注意事項](https://docs.m5stack.com/en/atom/Atom_Voice)

## 紫のLEDが点滅する

音声の入出力でエラーが起きています。USBを接続し直すか、本体をリセットしてください。
繰り返す場合は、Arduino IDEの **ツール → シリアルモニタ** を **115200 baud** で開き、`ERROR:` の行を確認します。

## シリアルモニタの見方

通常は `rms=... noise=... threshold=...` が表示されます。

| 表示 | 意味 |
| --- | --- |
| `rms` | 今のマイク入力の大きさ。約0.25秒ごとの表示なので、一瞬の拍手を表示しそびれることがあります |
| `noise` | 周囲の音の基準 |
| `threshold` | 大きな音と判定する基準 |
| `Clap` | 拍手らしい短い音を1回検出 |
| `Mode:` | ボタンで切り替えた再生モード |

再生中はマイクの読み取りを止めます。音声の録音・保存・ネット送信は行いません。

解決しない場合は、[Issues](https://github.com/hayakawagomichan/robokko-bell/issues)へ、本体名・ボードとライブラリのバージョン・LEDの状態・エラーの表示を添えて報告してください。
