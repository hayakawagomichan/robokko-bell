# ロボっこのクリスマスベル — ATOM Voice

<img src="docs/images/christmas-bell.jpg" alt="リボンとヒイラギで飾ったロボっこのクリスマスベル" width="560">

**パン、パン。手をたたくと、クリスマスの音がする。**

手のひらにおさまるATOM Voiceひとつで、拍手に反応するクリスマスベルをつくります。
ベルの音と「ジングルベル」を切り替えて遊べます。音に合わせて、LEDも赤と緑に光ります。

[なかよし！ロボっこ](https://github.com/hayakawagomichan/robokko)のシリーズとして、プログラムと使い方を公開しています。

本体のマイク・スピーカー・LEDを使うので、**追加の電子部品や配線は不要**です。
最初の書き込みにはPCとデータ通信対応USBケーブルを使います。書き込み後はUSBで電源を入れるだけで遊べます。Wi-Fiやスマホの設定はありません。

このリポジトリにはプログラムと説明資料が入っています。外装の3D印刷データは含まれていません。

## はじめに

このREADMEの書き込み手順は **ATOM Voice（旧名ATOM Echo／C008-C）** 用です。外装にはATOM Voice S3Rも取り付けられます。ATOM Voice S3Rを使う場合はS3R用のプログラムが必要です。
画面付きのATOM S3Rや、ATOM Lite・ATOM Matrix・EchoS3R・Echo Baseとは異なります。[本体の購入ページ](https://www.switch-science.com/products/6347)

音は内蔵スピーカーから鳴ります。マイク穴とスピーカー穴を、飾りやテープで塞がないようにしてください。

**書き込み済みの方は[遊び方](#play)から進めます。**

<a id="write"></a>

## 1. アプリを準備する（初回だけ）

1. [Arduino IDE](https://www.arduino.cc/en/software/)の2系をインストールして開きます。
2. Windowsは **ファイル → 基本設定**、MacはArduino IDEの設定を開きます。
3. 「追加のボードマネージャのURL」に、次のURLを追加します。すでに入力がある場合は残して追加します。

   ```text
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```

4. 左側の **ボードマネージャ** で `esp32` を検索し、**esp32 by Espressif Systems の3.3.8** をインストールします。
5. 左側の **ライブラリマネージャ** で `Adafruit NeoPixel` を検索し、**1.15.4** をインストールします。

このプログラムはESP32 3.xの音声APIを使います。**ESP32 2.xではコンパイルできません。** まずは上記の確認済みバージョンを選んでください。

## 2. ダウンロードして開く

1. [このGitHubのトップ](https://github.com/hayakawagomichan/robokko-bell)で **Code → Download ZIP** を押します。
2. ZIPを展開します。Windowsは右クリック →「すべて展開」、Macはダブルクリック。
3. `AtomChristmasBell` フォルダー内の **`AtomChristmasBell.ino`** をArduino IDEで開きます。

フォルダー名とファイル名はそのまま使います。**書き込むだけならプログラムの編集は不要**です。

## 3. 本体をつなぎ、書き込む

1. ATOM Voiceを、データ通信対応USBケーブルでPCにつなぎます。
2. **ツール → ボード → esp32 → ESP32 PICO-D4** を選びます。
3. **ツール → ポート** で本体のポートを選びます。Windowsでは `COM` から始まる名前が目印です。
4. **Upload Speed（書き込み速度）を115200** にします。それ以外はボードの標準設定を使います。
5. 左上の **右矢印「→」** を押します。コンパイルと書き込みが行われます。
6. USBを抜かずに待ち、書き込み完了の表示を確認します。

書き込むと、本体の元のプログラムは置き換わります。動き始めない場合は、本体のリセットボタンを押してください。

<a id="play"></a>

## 4. ベルを鳴らしてみる

1. 電源を入れたら、**最初の約2秒は静かに**待ちます。周囲の音を測っています。
2. LEDが黄色から**緑**になれば準備完了です。
3. 本体から20〜40cmくらいを目安に、**「パン、パン」と少し間をおいて**2回拍手します。
4. 1回目で青になり、2回目で「チリン、チリン」とベルが鳴ります。

拍手が拾いにくいときは、ボタンを約1秒押して、白くなったら離してみましょう。拍手なしでも試聴できます。

## 5. ジングルベルに切り替える

ボタンを短く1回押すと、LEDが**赤**になります。もう一度拍手2回で、約8秒の「ジングルベル」が鳴ります。
もう一度短く押すと、緑のベルモードに戻ります。

| 操作 | 動作 |
| --- | --- |
| 拍手を2回 | 選んでいる音を再生 |
| ボタンを短く押す | ベル（緑）／ジングルベル（赤）を切り替える |
| 約0.8秒長押しして、白くなったら離す | 拍手なしで試聴する |
| 再生中にボタンを押す | 再生を止める |
| 電源を入れ直す | ベルモードに戻り、周囲の音を測り直す |

再生中は拍手を受け付けません。終わってから約0.7秒待つと、次の拍手を受け付けます。

| LED | 意味 |
| --- | --- |
| 黄色 | 起動時に周囲の音を測っている |
| 緑 | ベルモードで待機 |
| 赤 | ジングルベルモードで待機 |
| 青 | 1回目の拍手を受け付け、2回目を待っている |
| 白 | 試聴の準備完了。ボタンを離すと鳴る |
| 赤・緑が交互に光る | 再生中 |
| 紫が点滅 | 音声の入出力エラー。[対処方法](docs/troubleshooting.md#purple)へ |

## 音の見本

[ベルを聴く](docs/audio/bell-preview.wav) ／ [ジングルベルを聴く](docs/audio/jingle-preview.wav)

見本はプログラムと同じ合成式から作ったWAVです。本体のスピーカーでは響きや音量が異なります。WAVを本体へコピーする必要はありません。

## うまくいかないとき

[書き込めない・拍手に反応しない・音量を変えたい場合はこちら](docs/troubleshooting.md)。

拍手らしい短い音の強さと間隔を使っているため、机を叩く音などにも反応することがあります。ワークショップ前に、使う部屋で距離や感度を確かめてください。
